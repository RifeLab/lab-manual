\date{\today}
\maketitle

\noindent The following checklist ensures all necessary steps are completed when a lab member departs.

\begin{itemize}[label=$\square$, leftmargin=*]
  \item Organize your RifeLab GitHub repo into projects with a README.md file outlining the contents.
    \begin{itemize}[label=$\circ$, leftmargin=2em]
      \item Ensure all code and data is accessible and has been uploaded to GitHub. Some services will become unavailable after your departure, so it is critical to upload materials to a location where they can be accessed.
      \item Include a summary of all in incomplete projects and what you think are the next steps. Think of this as a guide for the next person who will pick up where you left off.
    \end{itemize}
  \item Return all technology equipment to Trevor.
  \item Backup personal work and transfer data to the lab's shared drive.
  \item Submit final timesheets, expense reports, and reimbursements.
  \item Participate in exit interview with Trevor to discuss file organization, incomplete project summaries, and lab feedback.
  \item Provide forwarding physical and email address.
  \item Clean and organize your physical space (bench/desk/etc).
  \item Return all lab keys.
\end{itemize}
